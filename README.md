# Portfolio Website

This is my portfolio website created for the course 23CSE113 User Interface Design.

# Project Overview
This portfolio is a clean, responsive website built to document my academic progress and technical growth. It provides a central space to showcase my coursework, skills, and personal interests in a structured layout. Developing this project allowed me to gain hands-on experience in implementing semantic HTML5, mastering CSS layout techniques like Flexbox and Grid, and applying fundamental UI principles such as visual hierarchy and consistency to create a user-centered experience.
